# Улучшенная Додо Пицца — Демо-сайт

Сайт создан по запросу: меню в стиле Додо Пиццы (Березники) + улучшения по отзывам с оценкой 3+ + полная иерархия ролей + сгенерированные ники и формат паролей.

## Стек (как просил)

| Часть          | Технология      | Файл          |
|----------------|-----------------|---------------|
| Вёрстка        | HTML            | `index.html`  |
| Стили          | CSS             | `style.css`   |
| Логика фронта  | JavaScript      | `script.js`   |
| Бэкенд 1       | PHP             | `api.php`     |
| Бэкенд 2       | Go              | `main.go`     |
| База данных    | SQL             | `schema.sql`  |

## Что сделано

1. **Меню** — 12 пицц на основе реального ассортимента Додо + улучшения:
   - Больше сыра
   - Чёткие размеры 25/30/35
   - Акцент на «всегда горячая»
   - Хиты выделены

2. **Иерархия ролей** — полная таблица от Владельца до Заблокированного.

3. **Команда** — ники от Тестировщика до Основателя + ID в формате:
   ```
   user_foto_pizza_{название}_{цифра_пароля}_{random}
   ```
   Цифра пароля лежит прямо в ID.

## Как запустить

### Фронтенд
Просто открой `index.html` в браузере.

### PHP API
```bash
cd pizza-site
php -S localhost:8000
# потом http://localhost:8000/api.php?action=menu
```

### Go API
```bash
cd pizza-site
go run main.go
# http://localhost:8080/api/menu
```

### SQL
Импортируй `schema.sql` в PostgreSQL или MySQL.

## Пароли (как просил)

Пароль = одна цифра.  
Она зашита в ID пользователя.  
Пример:
- Ник: `Founder_DodoKing`
- ID: `user_foto_pizza_Pepperoni_7_9841`
- Пароль: `7`
